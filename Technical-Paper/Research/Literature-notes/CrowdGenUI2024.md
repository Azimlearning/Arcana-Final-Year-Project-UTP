# CrowdGenUI: Aligning LLM-Based UI Generation with Crowdsourced User Preferences

## What it does
Augments LLM-based UI generation with a crowdsourced user-preference corpus so that generated
interface controls reflect what real users actually want rather than what the model assumes. The
direct predecessor to AlignUI.

## Why it matters to Synapse
Marginal on its own. Its value is as the earlier reference in the alignment line — citing it with
AlignUI shows the trajectory rather than a single point, which reads as a properly surveyed Related
Work section.

Include only if the Related Work paragraph has room. With a 0.5-page budget for the whole section,
it is the first thing to cut.

## The gap it leaves
Same as AlignUI — preference alignment, not correctness. Additionally predates the 2026 capability
jump, so its findings about what LLMs can generate are already dated.
