# Scope — Early Planning Version (superseded)

> Authoritative current scope is in `arcana_prd.md` §7 (phase-tagged, changes as scope decisions land — e.g. ADR-017 pulled ML Engines back into P1). This is the proposal-stage version, kept for how the thinking started.

**In scope (as proposed):** PDF/DOCX/web-URL ingestion; KG construction; hybrid RAG (Graph+Vector+BM25+RRF); minimum 3 agents with A2A invocation; adaptive UI with ≥2 modes (Research, Study); quantitative benchmark vs flat RAG; user study (10–15 participants).

**Out of scope (as proposed):** video/audio ingestion+transcription; real-time collaborative multi-user KBs; mobile app; local/offline LLM inference; external academic DB integration (Semantic Scholar/arXiv) — note: Web Search Agent (academic discovery only) was added in the PRD, so this exclusion was later partially reversed.
