# Project Objectives

**Primary:**
1. Design and implement a graph-native hybrid RAG pipeline that outperforms standard vector-only RAG in cross-document retrieval accuracy.
2. Develop a composable multi-agent orchestration system (LangGraph) enabling autonomous task decomposition across specialised agents.
3. Build an adaptive UI with task-mode switching that dynamically reconfigures based on the user's current research/learning context.

**Secondary:**
1. Evaluate retrieval quality against a flat RAG baseline; informally compare against Google NotebookLM.
2. Implement persistent user context management (graph + interaction history across sessions).
3. Demonstrate applicability through a structured user study with student participants.

Compare against the PRD's current [[PRD-GoalsNonGoalsMetrics|Goals/Non-Goals/Success Metrics]] — the PRD is the authoritative, evolving version; this is the objectives as stated at proposal time.
