# Specialised Agent Suite — Early Planning Version (superseded)

> **Historical planning snapshot, kept for context only.** The current, authoritative agent suite (25 agents across 4 tiers, phased P0/P1/P2) lives in `Arcana/docs/arcana_prd.md` §12 and is actively built against in `checklist.md` — both change as the build progresses, so they are intentionally **not** duplicated here.

Original 6-agent plan:

| Agent | Primary Function | Key Outputs |
|---|---|---|
| Graph Agent | Traverse KG for hidden cross-document connections | Concept maps, entity chains, relationship summaries |
| Research Agent | Synthesise answers from multiple docs with citations | Cited summaries, comparative analyses |
| Learning Agent | Identify knowledge gaps, generate adaptive study materials | Flashcards, quizzes, concept summaries |
| Writing Agent | Draft structured documents grounded in the KB | Literature reviews, outlines, technical reports |
| Annotation Agent | Ingest user highlights/notes back into the graph | Enriched graph nodes, personalised context |
| Insight Agent | Surface unexpected connections, detect contradictions | Contradiction alerts, discovery cards |

All six survived into the PRD's expanded 25-agent suite in some form (Research, Graph, Learning, Writing, Annotation persist directly; Insight became the Discovery Agent).
